Grid viewer

This app lays out four to sixteen images that you generated elsewhere into one labelled grid, so that you can compare a controlled experiment, such as different seeds or guidance scales, side by side. Add your images below, name the variable that changes between them, and then save the grid as a picture or copy its captions as a table for your practice log. Everything happens on this device: images are read locally, never uploaded, and the state disappears when you leave the page.

    Grid settings

    Name the variable that you changed between the images, for example “guidance scale” or “prompt wording”. Leave the constant line blank if you do not need it, or use it to record what stayed fixed.

    Compare mode
    Add images above to use compare mode.

    Use the slider, the buttons, or the left and right arrow keys to step through the images one at a time and flick between two settings.

    A fair comparison changes one variable at a time and holds everything else fixed, including the seed, unless the seed itself is the variable under test. Write the exact settings for each image in your practice log, so that the comparison can be repeated later.

    How it works

    Each image file that you drop or choose stays in your browser’s memory. It is decoded locally and drawn onto a canvas element together with the title, captions, and footer text, without ever being sent anywhere. The Save button turns that canvas into a PNG file and offers it as a direct download. The Markdown button copies a small table of image numbers and captions to your clipboard, ready for pasting into a lab notebook or practice log. This app bundles no data files, so there is no licence to name.
