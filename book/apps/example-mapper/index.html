Example mapper

Teach the computer a mapping by example instead of writing a rule: place a few sounds on the pad, then press Run and move across it to play what it has learned. Nothing leaves the browser.

Input: the pad

Click or drag to place the marker. Its position is the input: two numbers, x and y.

On a phone, tilting can move the marker instead of a finger. The browser may ask permission first.

Output: the sound

Set the three sliders to a sound you like. While Run is on, they move by themselves.

Train

Add example stores the slider values at the marker and draws a dot there. The E key does the same. Five to ten examples are enough.

Run

While Run is on, moving over the pad sets the sliders from your examples. The colours show the learned mapping: hue for pitch, lightness for brightness.

Place the marker, set the sliders, and add an example.
More about this app

Interactive machine learning

Interactive machine learning builds a mapping by showing instead of telling. You give the computer a handful of examples, and each one pairs an input with the output you want at that input. The computer works out what to do everywhere else. This is supervised learning: every example comes with the right answer, and you are the one who supplies it. The best-known tool of this kind is Wekinator, made by Rebecca Fiebrink, which musicians and artists use to connect sensors to sound.

How it works

Each example stores a place on the pad and the three slider values you chose there. While Run is on, the app measures the distance from the marker to every example and picks the k nearest. This method is called k-nearest neighbours. The output is a weighted average of those neighbours, and a close example counts for much more than a distant one. With k = 1 only the single nearest example counts, so the pad splits into regions with hard edges. With a larger k the examples blend, and the sound glides from one to the next.

The colour field is the same calculation done for every cell of a coarse grid. The hue follows the pitch, from blue for low to red for high. The lightness follows the brightness. The pulse rate is not shown in the colours. Each dot has the colour of its own example.

The sound is one sawtooth oscillator. Pitch sets its frequency, brightness sets the cutoff of a low-pass filter, and pulse rate sets how fast the loudness swells and fades.

A small and transparent kind of AI

The whole model is the list of examples you gave it. Training takes an instant on a laptop or a phone, and you can see why every output comes out as it does. The large models elsewhere in this book are trained on enormous collections of data in data centres, and their inner workings are hard to inspect. Both kinds learn from examples. They differ in scale, and in who chose the examples.

Things to try

Add only two examples, far apart and with very different sounds. Run with k set to All and move from one to the other. Listen for where the sound changes most.

Add two conflicting examples close together: nearly the same place, very different sounds. Move slowly between them, and then far away from both. Notice how a tiny change in the input can now cause a large change in the output.

Add five or more examples and compare k = 1 with k = All. Look at the colour field and listen while crossing a border between two regions. Decide which setting you would rather perform with, and why.

While Run is on, stop at a place that sounds wrong, correct the sliders by hand, and add an example there. The mapping changes at once. This loop of trying, correcting and trying again is what makes the learning interactive.

Limits

Tilt needs a phone or tablet with motion sensors, and works best with the device held flat in portrait orientation. A laptop usually has no such sensors, so the pointer is the input there. The pad has two input dimensions, where a real sensor setup may have dozens. The examples are gone when the page is closed or reloaded.

Data

This app bundles no data and makes no network requests. The examples, the pointer position and the tilt readings stay in the memory of this page. Nothing leaves the device and nothing is stored.
