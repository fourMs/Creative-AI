Provenance inspector

Files carry traces of how they were made, and sometimes a signed provenance manifest. Drop in an image to see what it says about itself, and what it does not. Everything happens in this browser tab: the file is read locally with the FileReader API and is never uploaded anywhere.

This tool only reads and displays what a file already contains, such as EXIF camera fields, PNG text chunks, or a C2PA manifest's plain-text strings. It does not verify any cryptographic signature, so a "C2PA manifest present" result is a statement about presence, not authenticity.

What this does not tell you: the absence of camera or generator metadata does not mean a picture is unedited or human-made—metadata is easy to strip and easy to fake. A present C2PA manifest is not verified here either; treat every result as a clue, not a proof.
