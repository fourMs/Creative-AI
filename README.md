This is the source of the open textbook [Creative AI](https://fourms.github.io/Creative-AI/), written for a bachelor course at the University of Oslo that is open to students from every faculty. The book explains how generative AI works, shows how it is used in writing, image-making, music, video, code, 3D and games, and asks what stays human when machines can make things too. Every week ends in a lab that follows the same three moves: Explore, Reflect, Create.

You do not need to program to read it, and you do not need an account to use any of the small [browser apps](https://fourms.github.io/Creative-AI/apps/) that come with it. If you are here for the content, start at [the book itself](https://fourms.github.io/Creative-AI/).

## Run locally

    cd book
    jupyter book start

See the [wiki](https://github.com/fourMs/Creative-AI/wiki) for build instructions, the checks, the app conventions, and the chapter template.
